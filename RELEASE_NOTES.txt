Retani Studio theme for Moodle (theme_retani_studio)
Release notes
====================================================================

Version 1.1.0 (2026112404) - Release candidate
--------------------------------------------------------------------

Requirements
  - Moodle 5.3 (build 2026100200 or later)
  - PHP 8.3 or later

New
  - Front page: a landing page for the site home, after the "Moodle
    front page" design: announcement bar, header with a courses menu
    built from the course categories, hero, feature cards, course
    cards with category filters, about, statistics, instructors,
    testimonials, a call for instructors, news from the site
    announcements forum, a call to action and a footer with links,
    social networks and contact details.
  - Course cards show the course image, the number of students and
    activities, a "New" badge for courses created in the last 30 days,
    and the fee when the course has a payment enrolment method.
  - Course listing: Courses > All courses with the front page header
    and footer, a search by course name or teacher, filters by
    teacher and certificate, and a choice of sort order. Setting:
    "Use the Retani course listing".
  - The front page has no editing mode, user menu, notifications or
    messages in its header: it is the public face of the site.
    Logged-out visitors get a login button.
  - Three new settings tabs: "Front page", "Front page: people" and
    "Front page: news & footer". Every section can be turned off, and
    every text has a translatable default in the language pack. The
    standard site home is used when the landing page is turned off.
  - Light and dark mode toggle in the header of the front page and the
    course listing. The choice is remembered as a user preference for
    people who are logged in, and in a browser cookie for visitors.
    Setting: "Light and dark mode toggle" on the Front page tab
    (needs colour modes on).
  - Dashboard dark mode in the warm palette of the dashboard design:
    near-black canvas, dark cards and blocks, warm grey text and
    borders, dark avatars and buttons.
  - Dark mode for Site administration, for site administrators only,
    with a toggle in the top bar so each administrator can choose
    light or dark (dark by default). Setting: "Dark mode for Site
    administration". The choice is kept apart from the rest of the
    site: the front page toggle and the colour mode menu do not
    change it, and the colour mode menu is hidden on these pages so
    that there is only one dark mode control.

Changes
  - Maturity raised from beta to release candidate.
  - Dark mode no longer shows a light page background, form panels
    or icons: the light values set in post.scss are put back to the
    dark ones on every page.
  - Geist and Geist Mono are used for the front page and course
    listing.

Fixes
  - Settings saved from the page were lost on the next page load on
    sites where the /r.php REST routes are not reachable: the colour
    mode menu, the front page toggle, the administration dark mode
    toggle and the open or closed state of the drawers. They now save
    through the core_user_set_user_preferences web service
    (amd/src/preference.js).

Privacy
  - The new administration dark mode preference is declared in the
    privacy provider and included in data exports.

Upgrading
  - Purge all caches after upgrading. The new settings are listed on
    the upgrade settings page with the defaults of the design.

Known limitations
  - Colour modes are still experimental. Pages from third-party
    plugins that have not been checked in dark mode may still show
    light colours.

Version 1.0.0 (2026102607) - Beta
--------------------------------------------------------------------

First public release.

Requirements
  - Moodle 5.3 (build 2026100200 or later)
  - PHP 8.3 or later

Features
  - Based on Boost. Keeps the core markup that Moodle and other plugins
    rely on.
  - Retractable left navigation bar with the primary navigation, user
    menu and, inside a course, the course outline. Works as an
    off-canvas menu on small screens.
  - Collapsible block sidebar with icons for each block.
  - Redesigned split-screen login page: logo or site name, optional
    background image, and an image carousel of up to four slides.
    Slide titles, text, images and image descriptions can be changed
    in the theme settings, with translatable defaults in the language
    pack. The carousel respects the "reduce motion" preference and is
    replaced by the site's authentication instructions when these are
    set.
  - Refreshed course header and dashboard course overview (My courses).
  - Restyled quiz pages, including the quiz timer.
  - Restyled calendar navigation and view selector.
  - Restyled admin settings pages, with the theme settings grouped in
    tabs.
  - Optional light and dark colour modes (experimental, off by
    default), with a switcher for users.
  - Bundled Noto Sans and Noto Sans JP fonts.

Settings
  - General: unneeded blocks, theme preset (default, plain or Retani,
    or an uploaded preset), background image, login page background
    image, logo and brand colour.
  - Login page: number of slides (0 to 4) and, for each slide, its
    title, text, image and image description.
  - Advanced: raw initial SCSS and raw SCSS.
  - Experimental: enable colour modes and the default colour mode.

Changes during review
  - Added the LICENSE file (GNU GPL v3 or later) and README.md.
  - Added the standard Moodle licence header to all templates.
  - Renamed variables and methods to follow the Moodle naming
    conventions.
  - Moved all login carousel text, including image descriptions and
    button labels, into language strings.
  - Replaced the remote login carousel images with images bundled in
    pix/login.

Upgrading
  - Earlier development builds included a landing page and course
    catalogue. These were removed; the upgrade deletes their settings
    and uploaded images.
  - Purge all caches after upgrading.

Known limitations
  - Colour modes are experimental. Pages from third-party plugins that
    have not been checked in dark mode may still show light colours.
